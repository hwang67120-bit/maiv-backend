🏰 MAIV (Medieval AI Village)
Spring Boot + Ollama 기반 AI NPC 대화 시뮬레이션

🚀 프로젝트 소개
고정된 스크립트로 움직이는 기존 NPC에서 벗어나, LLM을 탑재한 NPC와 자유롭게 대화할 수 있는 중세 마을 시뮬레이션입니다.
핵심 목표:

NPC와 자유로운 AI 대화 (Ollama 연동)
대화 내용 DB 저장 및 히스토리 관리
Java Spring Boot로 LLM 파이프라인 구축
Python Pygame 클라이언트와 REST API 연동
